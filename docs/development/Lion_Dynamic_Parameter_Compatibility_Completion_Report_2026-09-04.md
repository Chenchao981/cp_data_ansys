# Lion 动态测试参数兼容完成报告（2026-09-04）

## 1. 目标与结论

本次修复 Lion V1 Excel 同一批次中测试参数增加、减少或更名时被误判为“内部规格不一致”的问题。

实现后，程序按文件内容自动识别 Lion 格式，逐文件动态解析测试参数，并在批次内按首次出现顺序合并参数并集。某片晶圆没有执行的测试项在 cleaned CSV 中保留为空值，不再阻止整批处理。

真实 `data4` 批次已经通过源码、GUI Worker、标准输出、图表和发布包全链路验证，可以用于交付。

## 2. 已完成工作

- Lion V1 Reader 不再依赖固定测试参数数量或固定参数名单；固定识别范围仅保留工艺字段前缀和规格行结构。
- 同一批次动态合并参数并集，支持不同 Wafer 的测试项增加或减少。
- 同名参数继续执行严格规格检查：单位、下限、上限或测试条件冲突时拒绝合并，并在错误中列出冲突文件。
- 增加输入数据防护：重复表头、重复坐标、重复 Seq、无效数值、非整数 Bin、重复 Wafer_ID 均明确报错。
- 标准 spec CSV 改为输出合并后的动态参数规格，参数顺序稳定可追溯。
- 图表自动发现实际测量参数，排除 `SITE_NUM`、`T_TIME`、`TEST_NUM` 等过程字段。
- 补充动态增减参数、规格冲突、非法数值、重复坐标和图表字段识别自动化测试。
- 同步更新 README、架构、数据契约、运维和发布说明。
- 重新生成并验证 `packaging/release/app.pyz`。

## 3. 业务规则

### 3.1 自动识别

Lion V1 通过工作表、固定工艺字段前缀、动态参数区及规格行标签共同识别，不根据文件名或测试程序名称猜测格式。

### 3.2 动态参数

- `TEST_NUM` 之后的非空列作为测量参数动态解析。
- 批次输出使用各文件参数的有序并集。
- 某个文件不存在的参数不填零，输出为空值，避免把“未测试”误判为真实测量值。

### 3.3 仍然失败关闭的情形

- 同名参数的单位、规格上下限或测试条件不同。
- 固定基础字段、工作表或规格行结构不符合 Lion V1 契约。
- 测量值或基础数值字段出现非数值内容。
- 同一 Wafer 内坐标或 Seq 重复，或同一批次 Wafer_ID 重复。

`pass_bin` 保持为 1，未改变良率业务规则。
